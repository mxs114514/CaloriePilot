# CaloriePilot 功能清单

## 一、产品定位

CaloriePilot 是一款面向个人减重场景的轻量级热量管理工具。

第一版聚焦个人自用场景，以“小而美”为目标，优先完成目标设定、热量记录、体重记录、计划打卡和历史趋势查看，帮助用户形成基础的减重数据闭环。

## 二、第一版目标

第一版需要让用户完成以下核心路径：

1. 首次进入时填写个人基础信息、偏好信息和计划信息。
2. 系统根据用户信息生成每日热量目标。
3. 用户每天记录每餐热量摄入和当日体重。
4. 用户在计划清单中完成日程打卡。
5. 用户在历史页查看摄入热量和体重变化趋势。
6. 用户在个人中心查看和维护个人资料。

## 三、MVP 功能范围

### 1. 首次使用

- 支持首次进入时填写基础信息。
- 支持首次进入时填写个性偏好。
- 支持首次进入时填写计划信息。
- 完成首次填写后进入记录页。

### 2. 底部导航

- 支持四个一级页面：记录、计划清单、历史、个人中心。
- 记录页作为默认首页。

### 3. 记录

- 支持展示每日热量状态。
- 支持记录每餐热量摄入。
- 支持记录今日体重。
- 支持展示今日目标、已摄入、剩余可摄入、当前缺口。

### 4. 计划清单

- 支持展示已制定日程。
- 支持对计划事项进行打卡。
- 支持展示计划事项完成状态。

### 5. 历史

- 支持查看计划内每日摄入热量趋势。
- 支持查看每日体重趋势。
- 支持通过折线图展示历史数据。

### 6. 个人中心

- 支持查看基础信息。
- 支持查看个性偏好。
- 支持查看计划信息。
- 支持查看 BMI 指数。
- 支持维护个人资料。

## 四、第一版暂不包含

- 不包含账号登录。
- 不包含云端同步。
- 不包含 AI 食物识别。
- 不包含复杂食物库。
- 不包含社交分享。
- 不包含提醒通知。
- 不包含运动消耗记录。
