# CaloriePilot 计算规则文档

## 一、计算规则目标

计算规则用于支撑第一版核心展示：

- 个人中心展示 BMI 指数。
- 记录页展示今日目标、已摄入、剩余可摄入和当前缺口。
- 历史页展示每日摄入热量和每日体重趋势。

第一版计算规则以清晰、稳定、可解释为优先，不追求复杂健康模型。

## 二、基础单位

- 身高：厘米，字段为 `heightCm`。
- 体重：千克，字段为 `weightKg` 或 `currentWeightKg`。
- 热量：千卡，字段单位为 `kcal`。
- 日期：`YYYY-MM-DD`。

## 三、BMI 计算

### 公式

```text
BMI = 体重kg / (身高m * 身高m)
```

### 字段换算

```text
heightM = heightCm / 100
BMI = currentWeightKg / (heightM * heightM)
```

### 展示规则

- BMI 保留 1 位小数。
- 当身高或体重缺失时，不展示 BMI 结果。

## 四、基础代谢率 BMR 计算

第一版使用 Mifflin-St Jeor 公式估算基础代谢率。

### 男性

```text
BMR = 10 * 体重kg + 6.25 * 身高cm - 5 * 年龄 + 5
```

### 女性

```text
BMR = 10 * 体重kg + 6.25 * 身高cm - 5 * 年龄 - 161
```

### 说明

- BMR 表示基础代谢率。
- BMR 结果单位为 kcal。
- BMR 结果取整数。

## 五、活动系数

根据用户填写的运动强度，为每日总消耗计算提供活动系数。

| 运动强度 | 字段值 | 活动系数 |
|---|---|---:|
| 低 | low | 1.2 |
| 中 | medium | 1.375 |
| 高 | high | 1.55 |

## 六、每日总消耗 TDEE 计算

### 公式

```text
TDEE = BMR * 活动系数
```

### 说明

- TDEE 表示估算的每日总热量消耗。
- TDEE 结果单位为 kcal。
- TDEE 结果取整数。

## 七、减重目标对应的每日热量缺口

第一版按以下规则估算减重目标所需的每日热量缺口：

```text
总热量缺口 = 减重目标kg * 7700
每日目标缺口 = 总热量缺口 / 计划时长天数
```

### 说明

- 7700 kcal 约等于 1 kg 体重变化对应的热量差。
- 该值用于产品估算，不作为医疗建议。
- 每日目标缺口结果取整数。

## 八、每日热量目标计算

### 公式

```text
每日热量目标 = TDEE - 每日目标缺口
```

### 说明

- 每日热量目标用于记录页的“今日目标”。
- 每日热量目标结果取整数。
- 如果计算结果异常，应提示用户检查基础信息和计划信息。

## 九、今日已摄入热量

### 公式

```text
今日已摄入 = 当天所有热量记录 calories 之和
```

### 说明

- 只统计 `date` 等于当天日期的热量记录。
- 单位为 kcal。
- 当天无热量记录时，今日已摄入为 0。

## 十、今日剩余可摄入热量

### 公式

```text
剩余可摄入 = 每日热量目标 - 今日已摄入
```

### 展示规则

- 结果大于 0 时，表示今天还可以摄入的热量。
- 结果等于 0 时，表示已达到今日目标。
- 结果小于 0 时，表示已超过今日目标。

## 十一、当前缺口

### 公式

```text
当前缺口 = TDEE - 今日已摄入
```

### 说明

- 当前缺口用于展示当天相对于估算消耗的热量差。
- 当前缺口不是剩余可摄入，两者含义不同：
  - 剩余可摄入：相对于每日热量目标。
  - 当前缺口：相对于每日总消耗 TDEE。

## 十二、圆环展示口径

记录页圆环围绕每日热量状态展示。

圆环核心展示项：

- 今日目标：每日热量目标。
- 已摄入：今日已摄入热量。
- 剩余可摄入：每日热量目标 - 今日已摄入。
- 当前缺口：TDEE - 今日已摄入。

### 进度比例

```text
摄入进度 = 今日已摄入 / 每日热量目标
```

### 展示规则

- 进度小于 100% 时，展示正常进度。
- 进度等于 100% 时，展示已达到目标。
- 进度大于 100% 时，展示已超过目标。

## 十三、历史页数据计算

### 每日摄入热量

```text
某日摄入热量 = 该日期所有热量记录 calories 之和
```

用于历史页每日摄入热量折线图。

### 每日体重

```text
某日体重 = 该日期保存的体重记录 weightKg
```

用于历史页每日体重折线图。

## 十四、数据缺失处理

- 缺少用户资料时，不执行每日热量目标计算。
- 缺少计划信息时，不执行每日热量目标计算。
- 缺少热量记录时，已摄入按 0 处理。
- 缺少体重记录时，历史体重图表中该日期不展示体重点。

## 十五、健康提示边界

CaloriePilot 第一版提供热量估算和记录能力，不提供医疗诊断。

当计算结果明显异常时，应提示用户检查输入信息。涉及特殊健康情况时，用户应咨询专业人士。
